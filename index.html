Selected academic work

Five courses that reflect my development in programming, object-oriented design, databases, systems analysis, and the integration of technical skills in a senior capstone project.

IT260

Advanced Programming

Course Description

The purpose of this course is to study the fundamental concepts and techniques necessary to write high-quality programs, including basic and advanced concepts of object-oriented approach, modular design, inheritance, GUI objects, exception handling, files and streams, and class libraries. These concepts and techniques are studied using the C# programming language and the .NET Framework in Microsoft Visual Studio.

Course Reflection

Advanced Programming helped me move beyond basic programming and think more carefully about how a complete application should be structured. Working in C# with the .NET Framework gave me experience with object-oriented programming, graphical interfaces, program logic, and organizing different parts of an application. I found this course especially relevant to my goal of becoming a software engineer because it showed me that good programming is not only about getting the correct output, but also about creating software that is organized, understandable, and practical for a user.

The course strengthened my critical-thinking and problem-solving skills because building an application required me to connect several concepts at the same time. When something did not work correctly, I had to trace the program flow, identify where the logic was failing, test changes, and make sure that one correction did not create another problem elsewhere. I became more patient with debugging and more comfortable breaking a larger problem into smaller pieces instead of trying to solve everything at once.

I also discovered that I learn programming best when I can turn concepts into something functional. Developing forms and connecting user actions to backend logic made object-oriented concepts feel much more concrete. The experience improved my attention to detail, independence, and confidence with C#. My selected project, the Student Grade Management System, brought these skills together in a Windows Forms application with a login flow, dashboard, student roster, grade editing, and student report generation. Building it reinforced the importance of validation, user experience, and connecting organized backend logic to an interface a user can operate.

IT280

Object Oriented Programming

Course Description

This course introduces core programming basics—including data types, control structures, algorithm development, and program design with functions—through the Python programming language. The course discusses the fundamental principles of Object-Oriented Programming, as well as in-depth data and information processing techniques. Students problem solve, explore real-world software development challenges, and create practical applications using graphical user interfaces, graphics, and network communications.

Course Reflection

Object Oriented Programming gave me a stronger foundation in Python and helped me understand how programming logic becomes an interactive application. The course covered core programming concepts while also introducing the principles behind object-oriented design. What I found most useful was learning to think about a program as a collection of smaller responsibilities rather than one long sequence of instructions.

Programming assignments required analytical thinking because I had to decide how to translate a problem into variables, conditions, functions, and user actions. Debugging was also an important part of the learning process. A small mistake in logic or in the way an event was connected to the interface could affect the result, so I learned to test individual parts of the program and work through errors systematically.

The course also showed me that I enjoy creating programs where I can immediately see how the user interacts with what I built. Working with Tkinter introduced me to graphical user interfaces and event-driven programming. I became more comfortable organizing Python code, connecting buttons and user input to program logic, and thinking about usability in addition to correctness. My selected sample is a Calculator application built with Python and Tkinter. Although it is a focused application, it represents an important stage in my development because it combined Python logic with a working graphical interface and gave me practical experience turning code into an application a user can operate.

IT330

Database Management Systems

Course Description

This course introduces the fundamental concepts of database management systems, with emphasis on the relational model, which is an increasingly important and widespread area in the computer field. Demonstrations and hands-on practice using ORACLE: SQL and PL/SQL reinforce the fundamental concepts.

Course Reflection

Database Management Systems changed the way I think about the data behind an application. I learned that a database is not simply a place to save information; its design determines how accurately and efficiently information can be stored, connected, retrieved, and analyzed. Because I am interested in backend software engineering, this course was especially valuable to me and helped connect programming with the data layer that supports real applications.

The course required critical thinking when identifying entities, deciding how information should be divided into tables, defining relationships, and writing SQL queries that answered a specific business question. In our final project, we worked through normalization and moved the design toward Third Normal Form, including separating shipping and retailer information to reduce dependencies. Working through these decisions helped me understand why database structure matters before queries are ever written.

I worked as part of a team on the Nintendo Database Management Systems Final Project, which strengthened both my technical and collaboration skills. We analyzed Nintendo-related data, identified core entities such as Product, Customer, Order, Shipping, and Retailer, normalized the design, created SQL tables, inserted data, and developed business-focused queries. My own query work focused on retail analytics and high-value customers: one query compared Nintendo hardware with retailer stock and pricing, while another connected customer, order, and product information to identify higher-value customers and calculate their spending. This project helped me see how thoughtful database design and SQL can turn stored data into useful business information.

Sample Project

Nintendo Database Final ProjectOracle SQL · Relational Design · Normalization · Analytics. Team database project covering entity discovery, 3NF design, SQL implementation, and business-focused queries.

IT295

Systems Analysis & Design

Course Description

This comprehensive study of the five phases of System Development Life Cycle (SDLC) and the System Analysis Toolkit shows the importance of communications, economic analysis, and project planning skills with current technologies across all phases of the SDLC. Students gain an in-depth understanding of how Information Systems support business requirements in today's intensely competitive environment. Real-world projects allow students to apply their knowledge individually and as members of a systems development team, acting as System Analysts to develop information-system solutions for business problems.

Course Reflection

Systems Analysis & Design taught me to look at technology from the business problem first instead of immediately thinking about code. I learned how the System Development Life Cycle provides a structured way to investigate a problem, gather requirements, define scope, analyze risks, model processes, and propose a solution. The course was important because it showed me that successful software depends on understanding what users and organizations actually need before development begins.

Our final project required a much higher level of analytical thinking than simply following a technical assignment. My team connected with TriState Commercial Realty and gathered information through an employee interview. We used what we learned to identify problems involving fragmented property listings, client information, financial records, duplication, and manual processes. Turning that information into requirements forced us to distinguish symptoms from underlying system problems and think about practical solutions.

Working as an analyst on a team also strengthened my communication and collaboration skills. I contributed to the preliminary investigation and project documentation while the team developed scope, risks, business and system use cases, functional and non-functional requirements, business rules, and a test plan. Our selected project, the Unified Real Estate & Financial Management System (UREFMS), proposed a centralized solution for TriState Commercial Realty covering client management, property management, financial reporting, role-based access, and integration with tools such as Buildout and QuickBooks, with a proposed React, Flask, MySQL, and AWS architecture. This experience taught me that strong systems analysis requires clear documentation, collaboration, and keeping technical decisions connected to real stakeholder needs.

Sample Project

Unified Real Estate & Financial Management System (UREFMS)Systems Analysis · SDLC · Requirements · Use Cases · Risk Analysis · System Design. A real-business analysis and design project developed from stakeholder research with TriState Commercial Realty.

IT495

Senior Seminar

Course Description

Under the guidance of a faculty advisor, students in their final semester are required to utilize their full scope of training and academic abilities in the design and development of an individualized computer-based management information system intended for business use. The project entails system conceptualization, detailed documentation, design, writing and testing of student-written software, hardware specifications, user training manuals, and other support materials. Students are also required to present and “sell” the project results formally, with projects and teams critiqued on content, approach, and professionalism.

Course Reflection

Senior Seminar is bringing together many of the skills I developed throughout the CIS program. Instead of concentrating on one technology, the course requires my team to think about an information system as a complete project with users, requirements, workflows, data, security, testing, documentation, and implementation decisions. Because this is my final-semester capstone, I see it as an opportunity to apply what I learned in programming, databases, systems analysis, and project management in one larger project.

Our team is developing an Employee Lifecycle & IT Asset Management System for a school or university environment. The system is intended to support employee information, onboarding, service-desk processes, IT asset registration and assignment, maintenance history, offboarding, asset recovery, access revocation, role-based access, task tracking, and related reporting. Working through this scope requires us to consider how HR, IT, service-desk staff, department heads, and administrators interact with the same system from different perspectives.

My primary responsibility is the database and backend area, including database/backend scope, technical and integration considerations, Microsoft API integration, and technical constraints. The project has strengthened my ability to think about dependencies between features instead of treating each requirement separately, while team coordination has strengthened my communication and project-planning skills. Because the project is currently in progress during Fall 2026, this portfolio sample represents the development process rather than a completed final product. I selected it because it best demonstrates how my technical interests are developing toward backend software engineering, and I will continue adding finalized database design, implementation, integration, testing, and documentation as the capstone progresses.
